# 💰 FinCalc - Sistema de Cálculos Financeiros em Python

O **FinCalc** é um sistema desenvolvido em Python com o objetivo de realizar diferentes cálculos financeiros de forma simples e automatizada.

O projeto foi desenvolvido como atividade acadêmica do curso de **Sistemas de Informação**, com foco na aplicação de conceitos de programação, funções, estruturas de decisão, cálculos matemáticos e organização de código.

---

## 📋 Sobre o Projeto

O FinCalc reúne diferentes funcionalidades relacionadas à matemática financeira em um único sistema.

Entre os cálculos disponíveis estão:

- Juros simples;
- Juros compostos;
- Planejamento de aposentadoria;
- Cálculo de IRRF;
- Depreciação linear;
- Financiamento pela Tabela Price;
- Valor futuro de investimentos;
- Conversão de taxa anual para taxa mensal equivalente.

A proposta é criar uma ferramenta que possa auxiliar na realização de cálculos financeiros básicos, além de servir como aplicação prática dos conhecimentos adquiridos durante a disciplina.

---

## 🚀 Funcionalidades

### 📈 Juros Simples

Calcula o montante final de um investimento utilizando o regime de juros simples.

**Parâmetros:**
- Capital inicial;
- Taxa anual de juros;
- Período em anos.

---

### 📊 Juros Compostos

Calcula o montante final considerando a incidência de juros compostos sobre o capital.

**Parâmetros:**
- Capital inicial;
- Taxa anual de juros;
- Período em anos.

---

### 👴 Cálculo de Aposentadoria

Estima o patrimônio acumulado ao longo dos anos considerando um patrimônio inicial, aportes mensais e uma taxa de rendimento anual.

**Parâmetros:**
- Patrimônio atual;
- Aporte mensal;
- Quantidade de anos;
- Taxa anual de rendimento.

---

### 🧾 Cálculo de IRRF

Realiza uma estimativa do Imposto de Renda Retido na Fonte (IRRF) com base no salário bruto informado.

**Parâmetro:**
- Salário bruto.

---

### 📉 Depreciação Linear

Calcula a depreciação anual de um ativo utilizando o método de depreciação linear.

- Valor inicial do ativo;
- Valor residual;
- Vida útil em anos.
